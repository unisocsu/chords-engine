ChordsEngine Windows

Windows software for song lyrics, audio transcription and guitar chord detection. Built around whisper.cpp and local processing. Five Windows editions are produced on every build, including a No Model edition for users who already have a compatible Whisper model.

קרדיטים

ChordsEngine Windows is a fork and continued development of the original chord-and-lyrics engine built with Claude Code by @tsoolgee.
