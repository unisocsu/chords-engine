ABOUT THE PROJECT

קוד פתוח. פיתוח מתמשך.

ChordsEngine Windows הוא fork והמשך פיתוח של מנוע האקורדים והמילים המקורי שנבנה באמצעות Claude Code על ידי @tsoolgee.

הפרויקט כולל אריזת Windows, מתקינים, מהדורות עם מודלים משולבים ו-builds אוטומטיים באמצעות GitHub Actions.
